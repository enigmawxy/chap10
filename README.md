# 知识图谱可视化项目

一个基于 Vue 3 + Vue Flow 的交互式知识图谱可视化工具，支持节点和连线的创建、编辑、删除等操作。

## 项目特性

- 🎯 **交互式图谱编辑**：支持拖拽创建节点和连线
- 🎨 **自定义节点样式**：可自定义节点外观和属性
- 🔗 **智能连线管理**：自动处理节点间的连接关系
- 💾 **数据持久化**：自动保存图谱数据到本地存储
- ⌨️ **快捷键操作**：支持键盘快捷键进行删除等操作
- 🎛️ **多选操作**：支持框选和 Ctrl+点击多选元素

## 使用说明

### 基本操作

1. **创建节点**：从侧边栏拖拽节点到画布
2. **创建连线**：拖拽节点的连接点到其他节点
3. **选择元素**：
   - 单击选择单个元素
   - Ctrl+点击进行多选
   - 拖拽框选多个元素
4. **删除元素**：选中元素后按 `Delete` 键
5. **编辑属性**：双击节点或连线进行编辑

### 快捷键

- `Delete`：删除选中的元素
- `Ctrl+点击`：多选元素
- `拖拽`：移动元素或框选

## 技术栈

- **前端框架**：Vue 3 + Composition API
- **图形库**：Vue Flow
- **构建工具**：Vite
- **样式**：Tailwind CSS
- **状态管理**：Vue 3 Reactivity
